# saros
取自Sarasvati(辩才天女 / 萨拉斯瓦蒂)印度教中的智慧、知识与艺术女神。她代表着知识的流动、语言的表达与深度的理解。-> Saras: 源自梵文，意为“本质”、“核心”或“灵魂”，象征着知识、艺术与智慧。->  相比于 Saras 略带宗教色彩和女性化的人名感，Saros 的发音更加中性、轻盈且充满呼吸感。它听起来不像是一个冷冰冰的机器，而更像是一个温柔、安静的“灵魂伴侣”。
在现实世界中，Saros（沙罗周期） 是一个真实存在的天文学名词，用来预测日食和月食的周期。日食和月食是宇宙规律的完美重现，而Saros系统是将“获取的新知识”与“过去的旧总结”进行碰撞和复用。暗示着你的知识不是用完即弃的碎片，而是像星辰运行一样，经过时间的沉淀，形成了一套属于你自己的、有规律的“认知宇宙”。
系统定位：Soras系统 是一位安静的“星际领航员”，强调“知识沉淀与复用”，不仅会“搜”，更懂得如何优雅、准确地“表达”和“内化”知识。
"沉淀即永恒"
目的：
Saros是一个结合了“联网搜索（Web Search）”与“检索增强生成（RAG）”的个性化智能知识库系统。这种系统不仅能帮获取外部信息，还能将外部知识转化为你的“私有资产”，实现知识的沉淀与复用。
